# MVP-agrikarta

Static React + Tailwind CSS MVP for AGRI-KARTA with three core sections:

- Public Landing transparency dashboard (mock moving average chart + warehouse availability)
- B2B Buyer dashboard (Grade A/B catalog + cart and checkout simulation with Rp 25.000 service fee)
- Admin/QC dashboard (functional logistics inspection status table)

## Development

```bash
npm install
npm run dev
```

## Build for Vercel

```bash
npm run build
```

The generated static output is in `dist/` and is ready for Vercel deployment.
